# Item pictures: source unconfirmed

These pictures were supplied by a community member (a Discord user) on 2026-10-21. Where they
came from is not confirmed, and we have not settled whether we may keep using them. They are
kept in this one folder so they are easy to remove, and nothing else depends on them.

Generated by `pnpm --filter @factions/web map:pictures` (resized to 192px from the originals).

## To remove them

1. Delete this folder.
2. Run `pnpm --filter @factions/web map:cards` (or reset each card's `image` in
   `../item-cards.json` and delete the `source.pictures` note). Cards go back to the wiki
   thumbnails, or no picture.
3. Award and booster kit tiles also use copies of some of these, in `apps/web/public/items/`.
   Every one is marked `wiki: "map"` in `apps/web/src/item-images.ts`: point each back at its
   wiki file (or drop its `image` from the catalogue JSON) and run `fetch-item-images.ts`.
